# 접근성 점검 (WCAG 2.1 AA 기준)

> 목적: 시력이 약하거나 화면 낭독기를 쓰는 학생도 제출·확인할 수 있게 — 평가 항목 '사용성'의 근거
> 점검일: 2026-11-19 · 대상: 관리자2·참여자 화면 14개 (로그인·대시보드·대회·프로젝트·제출 상세·리더보드·검토 큐·검토 상세·설정·회원·감사 로그 등)

## 1. 점검 방법

| 항목 | 기준 | 방법 |
|---|---|---|
| 글자 색 대비 | 일반 글자 4.5:1, 큰 글자 3:1 이상 | 실제 렌더링 화면에서 모든 글자의 글자색·배경색 대비 계산 (브라우저 스크립트) |
| 입력 라벨 | 모든 입력에 연결된 라벨 | 자동화 테스트 `apps/core/tests/test_accessibility.py` |
| 이미지 대체 텍스트 | 모든 `img` 에 `alt` | 〃 |
| 문서 구조 | 페이지마다 `h1` 1개, `html lang="ko"`, id 중복 없음 | 〃 |

## 2. 발견하고 고친 것

| 문제 | 영향 | 수정 |
|---|---|---|
| 보조 문구 회색 `#7a7a7a` — 대비 3.97~4.29 | 라벨·안내 문구 대부분이 기준 미달 | `#6b6b6b` (흰 배경 5.3, 회색 캔버스 4.9) |
| 연한 회색 `#a9a9a9` 를 글자에 사용 — 대비 2.35 | 해시값·단위·하단 안내 | 글자에는 보조 회색 사용, 연한 회색은 아이콘·구분 기호 전용 |
| 선택된 메뉴·번호 배지 파란 글자 — 4.29 | 현재 위치 표시 | 한 단계 진한 파랑 (5.4) |
| 빨간 글자(마감 임박·오류)에 화살표 색 `#f2462e` 사용 — 3.69 | 마감 남은 시간, 입력 오류 | 진한 빨강 `rose-700` (화살표·점은 기존 색 유지) |
| 초록·빨강 상태 글자(600 단계) — 3.5~4.1 | 순위 변화, 검토 의견, 의심 배지 | 700 단계 |
| '일괄 승인' 버튼 흰 글자/밝은 초록 — 2.47 | 관리자2 주요 버튼 | 진한 초록 배경 |
| 삭제 버튼 흰 글자/밝은 빨강 — 3.69 | 위험 작업 버튼 | 진한 빨강 배경 |
| 일괄 승인 체크박스·회원 검색·검토 의견·제출 코멘트에 라벨 없음 | 화면 낭독기가 "편집 가능 텍스트"로만 읽음 | `aria-label` 추가 |
| 마감일 수정 칸의 라벨이 입력과 연결되지 않음 | 라벨을 눌러도 입력으로 이동하지 않음 | `label for` ↔ `id` 연결 |
| 프로젝트 설정 화면에서 같은 id(`id_title`) 2개 | 두 번째 '이름' 라벨이 첫 번째 칸을 가리킴 | 마감일 폼 id 접두사 분리 (`dl_`) — **자동화 테스트가 발견** |
| 링크·메뉴·카드에 키보드 포커스 표시 없음 | Tab 으로 이동해도 현재 위치가 안 보임 (WCAG 2.4.7) | 모든 요소에 파란 포커스 테두리 (`:focus-visible`), 입력칸 포커스 링 강화 |
| '본문 바로가기' 없음 | 키보드 사용자가 매 화면 사이드바 메뉴를 전부 지나야 함 (WCAG 2.4.1) | 첫 Tab 에 나타나는 '본문 바로가기' 링크 |
| 휴대폰(375px)에서 대시보드가 가로로 넘침 (409px) | 좌우 스크롤 발생 | 화면 격자 칸이 긴 글자에 맞춰 늘어나지 않도록 (`minmax(0, 1fr)`) 11개 화면 일괄 수정 |

### 점검 중 발견한 오류 (접근성과 별개)

- 참여자가 **아직 채점된 제출이 없는 프로젝트가 있으면 대회 홈이 500 오류** — 점수 표시 필터가 빈 값을 처리하지 못함. 가입 직후 첫 화면이라 사용성 테스트 과제 1에서 바로 드러났을 문제. 수정 + 회귀 테스트 2개 추가

## 3. 결과

- 점검한 화면 14개 모두 대비·라벨·구조 기준 통과 (아바타 이니셜은 그라디언트 위 흰 굵은 글씨로 장식 요소)
- 휴대폰 폭(375px)에서 관리자·참여자 페이지 38개 모두 가로 넘침 없음
- 키보드: 첫 Tab 에 '본문 바로가기', 이후 모든 링크·버튼·입력에 포커스 테두리 표시 (실제 Tab 입력으로 확인)
- 접근성 자동화 테스트 5개를 CI 에 포함 → 새 화면을 추가해도 라벨 누락·id 중복은 테스트에서 걸러짐

## 3-1. 처음 로그인 사용 안내 (대화상자)

- `role="dialog"` · `aria-modal` · 단계 제목으로 이름 지정, 단계 번호는 `aria-live` 로 읽힘
- 키보드: ←/→ 단계 이동, Esc 닫기, Tab 은 대화상자 안에서만 순환, 닫으면 원래 위치로 포커스 복귀
- 단계마다 글 길이가 달라도 버튼 위치가 고정되어 같은 자리를 계속 누를 수 있음

## 4. 남은 것

- 색 대비는 브라우저 렌더링이 필요해 CI 자동화에는 넣지 않음 — 디자인 토큰을 바꿀 때 이 문서 1장의 방법으로 다시 점검
- 화면 낭독기(VoiceOver) 실사용 점검은 사용성 테스트 때 함께 진행 권장
