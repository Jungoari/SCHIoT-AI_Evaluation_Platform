# 0002. 정답 프로세스와 실행 프로세스의 물리적 분리

- 날짜: 2026-11-18 · 상태: 채택

## 맥락
RFP p.7: 참여자 코드 실행 시 정답·비밀키·다른 참여자 자료·관리 인터페이스 접근 차단. 정답 유출은 되돌릴 수 없다.

## 선택지
1. 같은 서버에서 실행하되 파일 권한·경로 검사로 막기 → 규칙 하나만 빠져도 뚫림
2. **정답이 아예 없는 곳에서 실행** → 막을 대상 자체가 없음

## 결정
- `worker`(채점): 정답 볼륨 O, 코드 실행 X — CSV를 데이터로만 파싱
- `sandbox-worker`: 정답 볼륨 X, Docker 로 샌드박스 컨테이너만 지시
- 샌드박스: 네트워크 없음·읽기 전용·비루트·권한 제거·자원 제한·매 실행 새 컨테이너, 작업 폴더엔 정답이 제거된 테스트 특성만

## 결과
- `sandbox_selftest` 공격 6종 실측 차단
- 트레이드오프: `sandbox-worker`는 Docker 소켓 때문에 root. 운영 시 rootless Docker 또는 gVisor 권장 (SECURITY.md)
