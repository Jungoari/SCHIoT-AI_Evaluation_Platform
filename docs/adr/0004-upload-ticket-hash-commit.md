# 0004. 마감 판정: 업로드 티켓 + 해시 선언

- 날짜: 2026-11-19 · 상태: 채택

## 맥락
RFP p.4: 마감 전에 업로드를 '시작'했으면 마감 후 완료돼도 채점. 클라이언트 시각은 조작 가능하고, 시작 시각만 기록하면 "마감 직전 티켓만 받아 두고 마감 후 더 좋은 파일을 올리는" 꼼수가 생긴다.

## 결정
1. `POST /p/<id>/submit/start/` — 서버가 시작 시각 기록, 브라우저가 계산한 3개 파일 SHA-256 을 함께 등록 (= 업로드 티켓)
2. 파일 수신 시 지문 대조, 불일치면 거부 (횟수 미차감)
3. 티켓은 프로젝트별 유예 시간(기본 30분) 안에 완료돼야 함
4. 큰 파일은 브라우저에서 4MB 조각 스트리밍 해시 (`static/js/sha256.js`, hashlib 과 결과 일치 테스트)
