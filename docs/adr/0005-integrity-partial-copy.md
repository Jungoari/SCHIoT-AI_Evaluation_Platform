# 0005. 부분 복사 탐지 지표 교체

- 날짜: 2026-11-19 · 상태: 채택 (이전 지표 폐기)

## 맥락
I-2 첫 버전은 "상대가 틀린 문항에서 같은 오답을 낸 비율(오답 일치율)"이었다. `integrity_experiment` 로 정직한 모델 20종을 측정하자 **정직한 제출 11/20 이 🟡/🔴** 로 표시됐다. 10클래스 숫자 분류에서는 서로 다른 모델도 같은 숫자(8↔1 등)를 같은 방식으로 헷갈리기 때문이다.

## 분석 (sklearn digits, 정직 20종 · 변형 복사 40건)
| 지표 | 정직(최댓값) | 변형 복사(최솟값) | 분리 |
|---|---:|---:|---|
| 오답 일치율 | 1.00 | 0.67 | 안 됨 |
| 드문 오답 일치율 | 1.00 | 0.00 | 안 됨 |
| **갈리는 행의 부자연스러운 답 비율** (다른 참여자 19명 기준) | **0.66** | **0.89** | **됨** |

복사본이 원본과 갈리는 행은 '손으로 고친 곳'이라 다른 모델 누구도 내지 않는 답이 된다. 정직한 모델은 갈리는 행에서도 다른 모델들이 내는 그럴듯한 답을 낸다.

## 결정
- 상대와 80% 이상 같고, 갈리는 행이 5개 이상일 때, 그 행들에서 내 답을 낸 다른 참여자가 5% 미만인 비율 ≥ 0.8 → 🔴, ≥ 0.7 → 🟡
- 비교 참여자가 10명 미만이면 '부자연스러움' 추정을 믿을 수 없으므로 🟡 까지만

## 결과
- 탐지율 90% → **100%** (30/30), 정직 오탐 🔴 10% → **5%**, 🟡 이상 55% → **5%**
- 남은 오탐 1건: 같은 random_state 의 의사결정나무 두 개 (사실상 같은 모델) — 사람이 확인하면 바로 구분 가능
