# 0001. Django 단일 애플리케이션 + HTMX

- 날짜: 2026-11-18 · 상태: 채택

## 맥락
- 개발 기간 7일, 1~2인. 보안 요구사항(행안부 가이드)이 무겁다
- 채점·검증이 Python(pandas, scikit-learn, nbformat) 생태계에 있다

## 선택지
| 안 | 장점 | 단점 |
|---|---|---|
| **Django + HTMX** | 인증·CSRF·세션·ORM·비밀번호 해시가 기본 내장, 언어 통일, 개발량 적음 | 화면 상호작용이 SPA보다 단순 |
| Next.js + FastAPI | 화면 표현력 | 인증·CSRF·권한을 직접 구현, 개발량 약 2배, 두 언어 |

## 결정
Django 단일 애플리케이션. 동적 갱신(채점 상태, 리더보드)은 HTMX 부분 갱신, 제출 화면만 소량의 순수 JS.

## 결과
- 보안 기본기를 프레임워크가 보장 → 남는 시간을 샌드박스·무결성 검사에 투자
- 인라인 스크립트 0개 → CSP `script-src 'self'` 유지
