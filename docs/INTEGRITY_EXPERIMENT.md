## 4. 해석

- 시스템은 🔴·🟡로 '어디를 볼지'만 알려주고 자동으로 부적합 처리하지 않는다. 최종 판단은 관리자1 → 관리자2.
- 🟡는 정직한 제출에서도 나올 수 있다 (예: 비슷한 모델끼리 오답이 일부 겹침). 그래서 🟡만으로는 판정하지 않고 근거를 함께 보여준다.
- I-6 격리 재실행은 비용이 커서 검토 대상에만 버튼으로 실행한다 (`--rerun` 으로 전체 측정 가능).
